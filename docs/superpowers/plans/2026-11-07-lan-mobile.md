# 局域网安全与移动可靠性实施计划

**目标：**按设计文档交付局域网安全直连和移动待处理事项闭环。

**架构：**网关负责 TLS、权限、请求生命周期及文件约束；Android 原生客户端负责用户确认、固定证书和事件重连；WebView 必须经原型验证后才可宣称全链路固定证书。优先保证失败关闭，不回退明文。

**技术：**Node.js 内置测试、Android Kotlin/Gradle、HTTPS/SSE/WebSocket。

## 阶段 1：基线及风险收敛
- [ ] 在工作树运行 `node --test *.test.js`（packages/gateway），记录结果。
- [ ] 设置 Android SDK 后运行 `./gradlew :app:assembleDebug`，记录构建结果。
- [ ] 为 WebView 的固定证书及 WebSocket 验证做隔离原型，验证失败则禁止声称安全会话完成。

## 阶段 2：独立的基础修复
- [ ] 网关：先添加已认证首页的集成测试，复现未导入布局变量；导入布局模块并验证首页和已有测试。
- [ ] 网关：以真实路径和符号链接测试约束工作区文件；限制文件读取和请求体，补充异常处理测试。
- [ ] Android：为审批和问题处理定义成功、失败、已处理状态；先写测试或验证用例，再实现错误可见和问题回答。
- [ ] Android：事件连接增加有界退避、状态与重连同步；验证 EOF、错误和撤销行为。

## 阶段 3：安全协议（依赖原型）
- [ ] 网关生成并持久化证书；保证私钥权限、身份稳定，缺损时失败关闭；公开本机证书指纹。
- [ ] 手机先探测证书并人工核对，重新握手校验指纹后才传配对码；禁止跨源重定向及明文令牌。
- [ ] 实现经验证的 WebView/WSS 全链路固定证书；撤销设备时关闭现有连接。
- [ ] 审批增加 60 秒可配置超时、回退和首次有效回答的原子语义；对多设备竞态编写测试。

## 阶段 4：集成验收
- [ ] 运行网关全部测试及 Android 干净构建；执行配对、会话、审批、问题、断线重连、文件越界和撤销联调。
- [ ] 在真实设备验证指纹变化、重定向、子资源和 WebSocket；不能验证的内容单独报告，不标记完成。
- [ ] 更新安装和安全说明；检查所有 diff 并进行设计符合性和代码质量审查。
